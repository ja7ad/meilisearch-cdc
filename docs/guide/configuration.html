Configuration reference

Every setting is optional: with none, the service listens on :8080, stores its state in ./data and is configured in the dashboard. Settings come from environment variables and command-line flags; a flag wins over its variable.

All settings

Environment variableFlagDefaultDescription
CDC_LISTEN-listen:8080HTTP listen address for the dashboard, API, /metrics and /mcp.
CDC_DATA_DIR-data-dir./dataDirectory of the state database cdc.db, the generated secret.key and the admin socket admin.sock. Created with mode 0700.
MEILI_URL-meili-urlemptyPins the service to this Meilisearch instance (single-instance mode). Leave it empty to manage destinations in the dashboard.
MEILI_API_KEY (falls back to MEILI_MASTER_KEY)-meili-api-keyemptyAPI key of the MEILI_URL instance. Secret: also MEILI_API_KEY_FILE.
MEILI_GZIP-meili-gziptrueGzip request bodies sent to the MEILI_URL instance.
MEILI_TIMEOUT-meili-timeout30sRequest timeout for the MEILI_URL instance.
CDC_ADMIN_TOKEN-admin-tokenemptyStatic bearer token with the admin role, for scripts, Prometheus and webhook pushers (details). Only its hash is kept in memory. Secret: also CDC_ADMIN_TOKEN_FILE.
CDC_SECRET_KEY-secret-keygenerated in secret.keyKey that encrypts stored credentials: a base64 string of exactly 32 bytes is used as the AES-256 key, anything else is a passphrase stretched with argon2id. Secret: also CDC_SECRET_KEY_FILE.
CDC_SECRET_KEY_PREVIOUSnoneemptyAn older key that can still decrypt; used for key rotation. Secret: also CDC_SECRET_KEY_PREVIOUS_FILE.
CDC_TASKS_FILE-tasksemptyYAML or JSON file of tasks applied at startup (declarative tasks); ${VAR} is expanded from the environment.
CDC_ADMIN_EMAILnoneemptyWith CDC_ADMIN_PASSWORD, creates the first admin at startup when no user exists (instead of the setup page). Its name is Administrator.
CDC_ADMIN_PASSWORDnoneemptyPassword of that first admin (8 to 128 characters). Secret: also CDC_ADMIN_PASSWORD_FILE.
CDC_PUBLIC_URL-public-urlemptyDashboard base URL used in emailed links. The URL saved in Settings → Email takes precedence; without both, the request's origin is used.
CDC_COOKIE_SECURE-cookie-securefalseAlways set the Secure flag on the session cookie (behind a TLS-terminating proxy).
CDC_TRUST_PROXY-trust-proxyfalseTrust X-Forwarded-For and X-Forwarded-Proto from a reverse proxy.
CDC_LOG_LEVEL-log-levelinfodebug, info, warn or error.
CDC_LOG_FORMAT-log-formattexttext or json. Logs go to standard error.
CDC_DISABLE_UI-disable-uifalseDo not serve the dashboard; the API, metrics and MCP keep working.
CDC_STOP_TIMEOUT-stop-timeout20sHow long a stopping task may drain pending batches before they are aborted (and replayed on the next start). The whole shutdown waits up to this plus 10 seconds.
CDC_PPROF-pproffalseExpose /debug/pprof/ to signed-in users (pprof).
CDC_ALERT_INTERVAL-alert-interval5sHow often alert rules are evaluated.

Value formats

  • Booleans accept 1, t, true, 0, f, false (any case). An unparsable value is ignored and the default applies.
  • Durations use Go syntax: 500ms, 30s, 2m, 1h30m. An unparsable value is ignored and the default applies.
  • Flags use one or two dashes: -listen :9000 and --listen=:9000 are the same.

The defaults shown are the effective values, so a variable already set in the environment appears as the default. meilisearch-cdc version (also -version, --version) prints the version, and meilisearch-cdc admin … runs the admin CLI.

Secrets and *_FILE

Five settings are secrets. Each can be read from a file whose path is in <NAME>_FILE, which is how Docker and Kubernetes mount secrets. Trailing \r and \n are removed. When the variable <NAME>_FILE is set and the file is readable, it wins over <NAME>.

SecretFile variant
CDC_SECRET_KEYCDC_SECRET_KEY_FILE
CDC_SECRET_KEY_PREVIOUSCDC_SECRET_KEY_PREVIOUS_FILE
MEILI_API_KEYMEILI_API_KEY_FILE
CDC_ADMIN_TOKENCDC_ADMIN_TOKEN_FILE
CDC_ADMIN_PASSWORDCDC_ADMIN_PASSWORD_FILE

MEILI_MASTER_KEY (the fallback for MEILI_API_KEY) has no file variant.

Credentials you enter in the dashboard (connector passwords, DynamoDB secret keys, Meilisearch API keys, the SMTP password, the Telegram bot token) are stored encrypted in cdc.db with AES-256-GCM and never returned by the API. See Secrets encryption.

Single-instance mode vs. destinations in the dashboard

meilisearch-cdc can write to many Meilisearch instances (destinations). How they are managed depends on MEILI_URL:

MEILI_URL unset (default)MEILI_URL set
DestinationsCreated, edited and deleted in the dashboard or the API. The first one becomes the default.One destination with the id default, marked managedByEnv. Its URL and key come from the environment and are refreshed at every start.
Other stored destinationsVisible and usable.Hidden.
Creating, deleting or switching destinationsAllowed (admin).Refused with 409: single instance mode: MEILI_URL is set, so the service writes only to that Meilisearch instance; unset it to manage destinations in the dashboard.
DashboardDestinations page with add/edit.GET /api/v1/auth/config reports "singleDestination": true and the UI hides destination management.

The service logs single instance mode: writing only to MEILI_URL at startup. To switch back to managed destinations, unset MEILI_URL and restart; the destinations stored earlier reappear.

Logging

Logs are structured (Go log/slog) and written to standard error. Every line carries the version attribute.

time=2026-10-26T23:41:57.571+03:30 level=INFO msg=listening version=v1.2.3 addr=127.0.0.1:8080 meilisearch=""

With CDC_LOG_FORMAT=json each line is a JSON object, convenient for Loki, Elasticsearch or CloudWatch. Per-task activity (snapshot started, streaming from a position, retries, holds) is also kept in memory, the last 1,000 entries per task, and shown on the task's Logs tab and streamed live.

pprof

With CDC_PPROF=true the Go profiler is served at /debug/pprof/ (index, profile, trace, symbol, cmdline). It requires authentication like the API: a session cookie or the admin token.

curl -H "Authorization: Bearer $CDC_ADMIN_TOKEN" -o cpu.pprof \
  "http://127.0.0.1:8080/debug/pprof/profile?seconds=30"
go tool pprof -http=:0 cpu.pprof

Who can read profiles

The flag's help text says "admins", but the route is registered as a read (GET) route, and reads are allowed to every signed-in role, viewers included. Enable pprof only while you need it.

Metrics

Prometheus metrics are always served at /metrics and need authentication. The metric names and labels are listed under Monitoring.
