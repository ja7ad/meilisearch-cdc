Development

meilisearch-cdc is written in Go with a dashboard in plain ES modules (Preact and htm, no build step), embedded in the binary. Tests range from unit tests to a full browser suite against every source.

Build from source

You need Go 1.27.3 or newer (see go.mod). The build is pure Go (no cgo), so it cross-compiles for every platform.

git clone https://github.com/ja7ad/meilisearch-cdc.git
cd meilisearch-cdc
make build                    # bin/meilisearch-cdc
./bin/meilisearch-cdc version # prints "dev"
make run                      # build and run

Release builds set the version with -ldflags "-X main.version=v1.2.3". cmd/meilisearch-cdc/default.pgo is used automatically for profile-guided optimisation (see PGO).

The full end-to-end environment

deploy/e2e/docker-compose.yml starts every supported source, two Meilisearch instances and a mail catcher. It is used by the full browser suite and is handy for trying the service by hand.

make e2e-env                                   # start and wait for every container
go run ./test/ui/lab serve -seed               # seed 300 products everywhere; :8799 changes data for the tests
make build
(set -a; . deploy/e2e/cdc.env; ./bin/meilisearch-cdc)   # http://127.0.0.1:8780, no MEILI_URL
make ui-full                                   # or: cd test/ui && SLOWMO=150 npx playwright test -c playwright.full.config.mjs --headed

The admin account and other test values are in deploy/e2e/cdc.env. deploy/e2e/reset.sh returns to a clean state (stop the service first): it removes the service data, the e2e_* indexes, inactive replication slots and Mailpit messages, and re-seeds every source. make e2e-env-down removes the containers and volumes.

The suite covers destinations, every source (snapshot of 300 rows, then insert, update and delete), email, members and roles (including the API's 403s), MCP, alerts, every page and tab, the task options (modes, mapping, DLQ, delete guard, resyncs, diff and repair, batch actions, import and export) and every Meilisearch index setting. With REAL_SMTP=1 ALERT_EMAIL=you@example.com the email and alert specs send real mail through the SMTP server saved in Settings. Details: docs/e2e.md.

This documentation

The guide is plain HTML in docs/guide/. Each page's content is its <article class="doc">; the head, navigation, breadcrumbs, pager, search index and sitemap-pages.json are regenerated from docs/guide/assets/nav.js by:

node docs/guide/build-search-index.mjs

Run it after adding or editing a page (add new pages to nav.js first). It needs Node.js 18 or newer and no dependencies.
